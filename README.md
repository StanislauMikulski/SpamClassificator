# Классификация спам-сообщений на базе BERT

**Автор:** Микульский Станислав  
**Дата:** 28.08.2026  

Проект по бинарной классификации текстовых сообщений (Spam/Ham) с использованием fine-tuning модели `bert-base-cased`. Модель демонстрирует высокую точность детекции нежелательного контента.

> **Результат:** F1-score = **97%** на тестовой выборке.

## Стек технологий

*   **Deep Learning:** PyTorch, HuggingFace Transformers
*   **Data Processing:** Datasets, Pandas, NumPy
*   **Training Optimization:** Accelerate
*   **Visualization & Metrics:** Matplotlib, Seaborn, Evaluate

## Анализ данных (EDA)

Исходный датасет содержит 5572 сообщения. Наблюдается дисбаланс классов:
*   **Ham (легитимные):** 4825 шт.
*   **Spam (спам):** 747 шт.

Анализ распределения длин сообщений подтвердил, что большинство текстов укладывается в лимит 200 токенов, что было использовано как параметр `max_length` при токенизации.

## Препроцессинг

1.  **Токенизация:** Использован `AutoTokenizer` от `google-bert/bert-base-cased`.
    *   Padding: `max_length`
    *   Truncation: `True`
    *   Max Length: `200`
2.  **Кодирование:** Маппинг категорий `ham` → `0`, `spam` → `1`.
3.  **Разбиение:** Train/Test split в пропорции 70/30 (`seed=42`).

## Обучение модели

Для обучения использовалась архитектура `BertForSequenceClassification` с двумя выходными нейронами.
